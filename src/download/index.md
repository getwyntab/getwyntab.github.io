# Download WYNTab

WYNTab is available for all major Chromium-based browsers.

## Browsers

| Browser | Link |
| :--- | :--- |
| **Google Chrome** | [Available on the Chrome Web Store](https://chromewebstore.google.com/detail/wyntab/hbfabaimiglbfjhcppfedgjkpfgabiff) |
| **Microsoft Edge** | [Download from Chrome Web Store](https://chromewebstore.google.com/detail/wyntab/hbfabaimiglbfjhcppfedgjkpfgabiff) |
| **Brave** | [Download from Chrome Web Store](https://chromewebstore.google.com/detail/wyntab/hbfabaimiglbfjhcppfedgjkpfgabiff) |
| **Vivaldi** | [Download from Chrome Web Store](https://chromewebstore.google.com/detail/wyntab/hbfabaimiglbfjhcppfedgjkpfgabiff) |

## Installation Steps

1.  Click the link for your browser above.
2.  Select **Add to Chrome** or **Get**.
3.  Confirm the installation by clicking **Add extension**.
4.  Wait for the WYNTab onboarding page to appear.
