# General FAQ

## What is WYNTab?

WYNTab stands for **Write Your NewTab**. It's a browser extension that lets you replace the default New Tab page with any custom HTML and CSS template.

## Why are scripts disabled?

For security and compliance with the Chrome Web Store's Content Security Policy (CSP), executable JavaScript within templates is restricted. However, you can achieve complex layouts and animations using pure CSS.

## Can I use external images?

Yes, as long as the external server allows its images to be embedded (no strict CORS or hotlinking protections), you can use them in your HTML.

## Is WYNTab free?

Yes, WYNTab is completely free and open-source. You can find the source code on [GitHub](https://github.com/getwyntab/wyntab).

## How do I request a feature?

You can suggest features or report bugs via our [GitHub Issues](https://github.com/getwyntab/wyntab/issues).
