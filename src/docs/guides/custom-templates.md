# Custom Templates

One of the most powerful features of WYNTab is the ability to use your own HTML files as a New Tab page.

## Uploading an HTML File

1.  Open the **Dashboard** and go to **Custom Library**.
2.  Click **Upload HTML**.
3.  Select any `.html` file from your computer.
4.  WYNTab will automatically [sanitize](./security-and-privacy) the file and add it to your library.

## Using the Integrated Editor

WYNTab includes a full-featured code editor (powered by CodeMirror 6) that allows you to write HTML and CSS directly in the browser.

1.  Click **Create Live** in the Custom Library.
2.  Use the editor on the left; the preview on the right updates in real-time.
3.  **Scripts Note**: For security reasons, `<script>` tags are disabled. See our [Security Policy](./security-and-privacy) for more details.

## Template Ideas

- **Minimalist Clocks**: Use CSS animations and transitions for a clean aesthetic.
- **Link Dashboards**: Create a grid of your most visited sites.
- **Project Lists**: Use your new tab as a simple to-do list.
- **Atmospheric Visuals**: Use CSS gradients and blurs for a focused environment.
